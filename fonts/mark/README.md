# Mark fonts (build inputs only)

Subsets used by `tools/build_marks.py` to outline the marks; the generated SVGs need no font.

- `sourndMark.woff2`: Bricolage Grotesque 96pt Bold, glyphs s O U R n d. The exact font file
  `design/SourndMark.dc.html` loads (fonts.gstatic.com kit). SIL Open Font License 1.1,
  Copyright 2022 The Bricolage Grotesque Project Authors.
- `JetBrainsMono-Bold.woff2`: JetBrains Mono Bold, glyphs for FUZZ, COMP and GATE, the face
  `design/SourndAppIcon.dc.html` names for the icon labels. SIL Open Font License 1.1,
  Copyright 2020 The JetBrains Mono Project Authors.
