# Changelog

The version is the brand kit's own, in semver. The **major version is the brand generation**: a
new sournd brand ships as a new major version, so a product pins the major it was designed with.
Minor versions add files, sizes or packages; patch versions fix files without changing the look.

## 0.1.0 (4 Oct 2026)

The first release of the sournd brand.

- Wordmark: sOURnd in Bricolage Grotesque Bold, with the O knob, U fader and R jack. Light and dark
  versions, as SVG and PNG.
- Icon: the Bricks tile in three cuts. Full (48px and up) with FUZZ, COMP and GATE written out;
  small (20 to 32px) with fuzz, comp and gate symbols; tiny (16px), a prompt and a wave. PNGs from
  16 to 1024px, favicons and app icons.
- Colour: paper, ink, night, chalk; light petrol as the one accent; raspberry for controls; amber
  for highlights; button states for light and dark.
- Type: Bricolage Grotesque 700 for headings, Instrument Sans for everything else.
- Interface: radius, heights, borders, focus and status rules.
- Tokens as JSON, CSS custom properties and the Design Tokens format (Figma, Tokens Studio).
- Packages for npm, Composer, Python, Swift and Rust, each exposing the version.
